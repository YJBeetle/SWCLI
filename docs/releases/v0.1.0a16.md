# SWCLI v0.1.0a16

## 文件摘要与自定义属性

新增文件摘要读取，以及标题、主题、作者、关键词、备注五个字段的受保护写入。备注在保存重开前后统一换行表示。

自定义属性新增显式配置作用域读取、属性汇总，以及新增、修改和删除操作。写入沿用文档租约、会话、更新戳和预期旧值检查，返回实际读回值及可能发生变更的状态。读取保留原始表达式、求值、原生类型和解析状态，区分空值与缺失属性。

开发版 Windows 原始回执已独立验证零件和装配的摘要写入、文档与配置属性隔离、文本属性增改删、条件拒绝和另存只读重开。数值、布尔字段的初始读取也有原生样件证据。其他类型创建路径保留便携测试覆盖，后续补充专项原生样件。

工程图属性样件和“选项 → 文档属性”中的单位、字体及绘图标准在后续版本逐步推进。用户要求合入的官方 API 指南来源 `16075bd5c68f8f2898310a8b5763c6eb85972b87` 继续保留。

## 测试与验收

普通 CI 运行单元测试、安装后命令冒烟和打包检查。手动选择 `native_full=true` 执行完整 Windows SOLIDWORKS 验收。开发 API 校准在本地 Windows 虚拟机完成，DockerSW 保留完整 Wine 门禁后晋升镜像。

开发版已通过 [Windows 原生验收](https://github.com/YJBeetle/SWCLI/actions/runs/42075071140) 的独立核验，包括完整十九组二十步、四十八例多边形、十二例贯穿和真实导出。此提交冻结精确版本 `0.1.0a16`，最终 Windows 原始安装包与完整功能验收仍待完成。当前未发布，正式发布须用户最终确认。
