# SWCLI v0.1.0a14

## 三角形和凹 L 形定深编辑

`feature set-depth` 支持以单闭合三角形或轴对齐六边凹 L 形为轮廓的定深拉伸和切除。写入前确认原生草图归属、轮廓和特征定义，并沿用文档租约、版本戳及作用域检查。实际写入后的回执包含读回深度、几何与提交状态。同深度调用保持特征深度，mutation 标志显示未提交写入。既有圆和矩形行为及多边形贯穿切除限制保持。

发行包随附 SOLIDWORKS API 指南。该指南来自已合并的 `16075bd5c68f8f2898310a8b5763c6eb85972b87`。

## 验收

开发版 `fff5e0a21362beb9f08b42c58924c811a484ade1` 的 [Windows 公共门禁](https://github.com/YJBeetle/SWCLI/actions/runs/41844896304) 和 [Wine 公共门禁](https://github.com/YJBeetle/DockerSW/actions/runs/41858683707) 均已完成独立复核。每个宿主覆盖 48 个多边形、四次实际深度修改、四次同深度调用和 12 个既有贯穿切除用例。验证包含保存后只读重开的定义、几何和文件哈希。
