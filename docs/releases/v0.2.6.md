# SWCLI 0.2.6

## Changes

- Select a native mode with `document open --mode`. Parts support Resolved
  and Quick View. Drawings support Resolved, Lightweight and Detailing.
  Assemblies support Resolved, Lightweight and Large Design Review. The
  receipt reports the observed native mode. Omit the mode to keep the
  previous open behavior.
- For assemblies opened in Resolved or Lightweight mode, choose whether
  to load hidden components, use SpeedPak or use Large Assembly Settings.
  The Large Assembly Settings option applies during the open on a
  daemon-owned host and restores the host preference afterward.
- Create partial revolve bosses at 45°, 90°, 180° or 270° on the Front,
  Top or Right origin plane. The supported partial-turn profile is a
  10 × 20 mm rectangle with bounds `[0, -5, 10, 15]` in sketch coordinates,
  revolving along its left edge. The existing full-turn scope still applies.
- Read and write two drawing detailing defaults for new views. Set
  automatic center lines and connection lines for hole-pattern center
  marks. Writes compare all four related defaults and keep the existing
  document, lease and update-stamp checks.
- Allow an export to finish when SOLIDWORKS only changes the source save
  flag during the operation. Strict exports still reject modified or
  rebuild-required sources before export, and reject source identity or
  rebuild-state changes afterward. Explicit STEP and STL options keep
  their additional checks.

## Compatibility

The native acceptance baseline is Windows SOLIDWORKS 2025 SP5. Opening
modes are available through the CLI, Python SDK and MCP. Close an open
document before explicitly selecting its mode. Check the returned state
when SOLIDWORKS mixes component load modes or falls back to a different
mode. Partial revolutions and drawing detailing writes follow their
validated host and input constraints.
