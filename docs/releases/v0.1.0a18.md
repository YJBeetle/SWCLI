# SWCLI v0.1.0a18

状态：精确版本冻结，尚未发布；最终 Windows CI 与原 CI 安装包仍待核验。

新增“选项 → 文档属性 → 注释”的七项标量设置：三类附着箭头样式、水平折线开关、引线长度（毫米）、前导零和尾随零。通过 `document annotation-options` 读取，通过 `document annotation-option-set FIELD VALUE --if-value OLD` 单字段修改。枚举写入范围以当前显式目录为准，不代表全部箭头、全部注释选项或整个文档属性页面已完成。

写入继承文档租约、会话和更新戳，并强制比较预期旧值。实际修改后完整读回七字段、验证未请求字段和文档上下文保持，必要时标记需要保存。同值不调用偏好 setter；原生失败保留可能已改变的状态，不重试、不自动回滚、不隐式保存。只操作目标文档的偏好，不修改应用全局默认设置。

工程图普通sheet本身具有活动草图，本版按sheet/view/sketch/template原生身份及编辑模式识别该正常上下文；图纸格式、模型view或其他草图编辑等不支持上下文拒绝改变。只读操作保留已有上下文。长度显示单位与精度以及此前摘要/自定义属性能力继续保留。

字体和总体绘图标准尚未开放。A18完成后暂停，不自动推进下一版；main/MCP最终合并由另一位agent负责，本候选不处理DockerSW跟进。

开发提交 `a3d70b18bb98e426442744ce40841a65d281e094` 的本地安装版公共专项已完成：零件、装配、工程图各七字段异值保存只读重开，以及三箭头反向保存重开；147条真实请求trace证明30次偏好setter、6次标脏，21次同值请求零setter，并核对拒绝条件、状态、文件hash、几何与清理。独立图纸格式编辑负例已验证在setter前拒绝，且不自动切回图纸模式。开发诊断与公共专项分开记录，专项不替代完整CI。

本提交只冻结版本字串和证据/发布说明，产品适配器与该开发提交相同。最终完整 Windows 验收、最终原始 wheel/sdist 来源与公开发布仍待完成；正式发布须用户最终确认。
