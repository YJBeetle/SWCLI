# SWCLI v0.1.0a18

新增“选项 → 文档属性 → 注释”的七项标量设置：三类附着箭头样式、水平折线开关、引线长度（毫米）、前导零和尾随零。

- `document annotation-options` 读取七字段及对应原生值。
- `document annotation-option-set FIELD VALUE --if-value OLD` 在显式支持目录内单字段修改，受文档租约、会话、更新戳及预期旧值保护。
- 修改后完整读回七字段，保持未请求字段、后台文档和编辑上下文；同值请求不调用偏好 setter。原生失败保留部分修改信息，不重试、不回滚、不隐式保存。
- 支持普通工程图 sheet，包括缺少图纸格式的 sheet；格式编辑、模型 view 或不匹配草图上下文拒绝修改。
