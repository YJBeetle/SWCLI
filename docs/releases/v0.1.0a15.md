# SWCLI v0.1.0a15

## 文档级自定义属性读取

新增 `document properties [--name NAME]`，通过现有 daemon 和文档句柄读取 SOLIDWORKS 文档级自定义属性。结果包含属性名、原生类型、原始表达式、求值及缓存/解析标志。已有空值保留一行；缺失名称返回空列表。后台目标、会话与版本戳检查沿用现有规则，读取前后校验原生状态不变。

本版已验证的样件范围为零件和装配的文档级属性。配置专属属性读取、工程图样件验证及属性新增/修改/删除留待后续小步实现。随包 SOLIDWORKS API 指南保留已合入的 `16075bd5c68f8f2898310a8b5763c6eb85972b87` 来源。

## 验收状态

开发版已通过 [Windows 公共 CLI 门禁](https://github.com/YJBeetle/SWCLI/actions/runs/41990395318) 和 [Wine 公共门禁](https://github.com/YJBeetle/DockerSW/actions/runs/42005850194) 的原始证据独立复核。Wine 含 0020 空 XML 命名空间修复，实际另存零件和装配后关闭、只读重开，属性原值/求值/类型与文件哈希均符合预期；既有完整 CAD 矩阵、导出与 visible 也通过。

此提交冻结精确版本 `0.1.0a15`，最终双宿主门禁和最终原始 CI 包验收尚待完成。当前未发布，正式发布须用户最终确认。
