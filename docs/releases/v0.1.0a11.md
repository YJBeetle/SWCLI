# SWCLI v0.1.0a11 — development

Not published; a10 remains the current pre-release. New operations require a
matching development client and daemon.

```bash
sw-cli document create --type drawing --template A4.DRWDOT --projection third-angle --json
sw-cli drawing standard-views SOURCE_DOCUMENT_ID --configuration CONFIGURATION --document DRAWING_ID --json
```

The first creation slice uses calibrated A4 paper, an explicit existing DRWDOT
and explicit first/third-angle projection. It does not promise arbitrary paper
inheritance or generate templates. A missing legacy external format path is
reported, never silently replaced. Embedded title-block fidelity is not proved
by that warning or by export file validation.

Standard views require an empty single-sheet writable drawing and an already
open, saved, clean, rebuilt PRT/ASM in the explicitly named active configuration.
It never switches or saves the source configuration. Target lease/CAS and
cross-document guards run before activation; a source leased by another session
is refused. Temporary activation restores the previous foreground without
changing session current. Sheet/view positions and outlines use meters.

Exactly three model views must agree with native source/configuration,
calibrated standard-frame matrices, scale and nonoverlapping paper layout.
Custom model view frames may be refused; no automatic dimensions, BOM, arbitrary
layout, section views or multiple-sheet editing are included. Partial insertion
retains mutation/view/error evidence; no automatic retry, deletion or rollback.

## Shared gate integration

The full runtime plan adds a separate owned-host `drawings` set; the core plan
and six delivery exports are unchanged. It composes only public CLI operations
for first-angle PRT and third-angle generated ASM drawings, lease/CAS refusals,
background identity, native save/reopen, public structure/diagnostics and strict
PDF/DWG exports. Reopened view transforms/references are not publicly exposed
by document inspection; this gate does not claim their independent readback.
The separate native calibration retains that stronger persistence evidence.

Host adapters supply an explicit installed A4 DRWDOT. Fixture discovery accepts
one exact `templates/gb_a4.drwdot`, or an explicit `SWCLI_DRAWING_TEMPLATE` path;
missing/ambiguous fixtures fail rather than selecting an arbitrary template.
Portable full suite passed 1416 tests (20 platform skips) during integration;
wheel/sdist verification and isolated installed resources passed. These are
not fresh native CI receipts. The agent guide now includes the drawing workflow
and does not advertise it as part of published a10.
