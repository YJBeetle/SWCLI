## Public operation

```powershell
sw-cli document create --type part --json
$sketch = sw-cli sketch polygon --plane front --vertices-mm '[[0,0],[20,0],[0,15]]' --json | ConvertFrom-Json
sw-cli feature extrude $sketch.sketch.sketch_id --depth-mm 10 --json
```

`sketch.polygon` takes a standard `plane` (`front`, `top`, `right`) and 3–64
ordered `vertices_mm` objects `{x,y}` in sketch-local millimeters. CLI numeric
pairs map to this object-array protocol field. Closure is implicit; do not
repeat the first vertex. Both windings and simple concave outlines are supported.
Native nonconstruction lines must form exactly one closed contour and match
the complete requested endpoint cycle after sketch solving. The receipt includes
signed area, perimeter, centroid, native closure and an exact sketch handle.

Preflight rejects malformed nested data, booleans/nonfinite coordinates,
repeated or ambiguous vertices, redundant collinear corners, short edges,
self crossing/touching/near-touching and numerically ambiguous/sliver geometry.
There are no holes, arcs, automatic repairs or inferred driving constraints;
coordinate placement does not promise a fully defined sketch.

Fresh unabsorbed polygon sketches can use existing blind extrusion/cut commands.
Cutting requires an appropriate existing solid. Through-all and feature depth
editing retain their existing circle/rectangle profile restrictions. This slice
does not add polygon parameter editing or weaken those guards.

Lease/CAS, document-local handles and temporary background activation remain
required. Failed partial creation retains the exact surviving sketch handle when
available, including when descriptive metadata could not yet be read. Restoration
failure cannot report success. No rollback, failed-native retry or group-internal
host restart is introduced; product native deadlines and geometry checks remain.
