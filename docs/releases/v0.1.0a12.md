## Public operation

```bash
sw-cli feature cut-extrude SKETCH_ID --through-all --document DOCUMENT_ID --lease LEASE_ID --json
sw-cli feature cut-extrude SKETCH_ID --through-all --reverse --document DOCUMENT_ID --lease LEASE_ID --json
```

`feature.cut-extrude` accepts `end_condition=blind|through-all`. Omitting the end
condition preserves existing blind-depth behavior. CLI `--depth-mm` and
`--through-all` are mutually exclusive; a through-all request rejects any depth
field, including null. Reported depth, measured depth and depth tolerance are null
for through-all; the unused native placeholder is never reported as travel.

This slice supports one direction, exact registered unabsorbed full-circle or
axis-aligned rectangle sketches on front/top/right planes, no pre-existing
selection and one solid body without other body types. Native all-body scope is
used with feature scope and automatic scope selection disabled. Arbitrary
profiles, multiple bodies, two-direction termination and through-all depth edits
are outside this slice. `feature.set-depth` remains blind-only.

Lease/CAS checks, exact created-feature handles and background document restoration
remain required. A post-create verification failure retains its exact handle;
selection cleanup failure cannot report success. There is no implicit rollback,
failed-native retry or group-internal host restart.
