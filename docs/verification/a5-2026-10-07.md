## Native binding lesson

Checking the truthiness of `SetUserPreferenceToggle` falsely rejected a working
native setter, because this late-bound host returns `None`. The adapter verifies
the actual preference via `GetUserPreferenceToggle`, both after suppression and
after restoration. A regression test covers the successful void-return setter;
other tests require failure/warnings when the actual state is wrong. No consent
dialog was accepted and no licensing registry flag was modified.

## Typed operations and installed Windows wheel

The development branch now exposes `sketch.dimension-diameter`,
`dimension.inspect` and `dimension.set` through the one daemon-backed protocol.
Creation/set obey lease/update-stamp/document/session guards; inspect does not
activate, select, rebuild or enter an edit. A short `m-xxxxxx` retains the exact
native dimension and its owning registered sketch, even after a partial failed
creation. Close/reopen or worker replacement invalidates handles. Native document
identity distinguishes external same-path reopening from wrapper replacement;
known disconnected proxies expire, while busy/unknown comparison errors fail
closed. Foreground restoration is verified without losing mutation evidence.

The portable suite reached **345 passing tests** after protocol, registry,
adapter, Schema and gate additions. This includes exact ownership, equation and
design-table refusal, driven/read-only state, failure/false-success evidence,
stale IDs, guarded background writes and restoration failure coverage.

An isolated Windows environment installed the built `0.1.0a5.dev0` wheel, without
`PYTHONPATH` or an editable source override. The gate invoked the installed CLI
for front-plane create/inspect/set and the same public protocol on top/right.
All three planes passed:

- diameter 16 mm -> extrusion 10 mm -> absorbed diameter edit to 20 mm;
- native radius/center, volume 2010.619298297468 -> 3141.5926535897966 mm³ and
  final area 1256.6370614359182 mm²;
- read-only stamps, cross-session lease/CAS refusal, duplicate refusal and exact
  foreground/session-current restoration;
- native save/reopen measurement and feature diagnosis, rejecting old sketch
  and dimension IDs after close/reopen.
