## Remaining release gates

1. Obtain useful native stacks and localize the complex repeat-load failure;
   any repair needs a focused regression, not increased timeouts or retries.
2. Run complete Mac hidden-full with the original assertions and all expected
   sets. A successful simple drawing, fresh first open or standalone COM control
   cannot substitute for this gate.
3. Freeze a matching final SWCLI/host candidate. Keep host-owned path/template/
   environment wiring separate from shared CAD semantics.
4. Reuse that verified candidate's original CI distributions, check installation
   and hashes, then prepare the publication provenance. No a11 tag or assets are
   authorized by this documentation update alone.
